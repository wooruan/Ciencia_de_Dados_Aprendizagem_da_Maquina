## 2. Objetivo da atividade

Nesta atividade, sua equipe deverá analisar um **problema real** e pensar como uma equipe de Ciência de Dados poderia utilizar dados para compreender a situação e apoiar uma decisão.

O objetivo não é desenvolver um sistema ou modelo de Machine Learning neste momento.

O objetivo é aprender a **pensar como um cientista de dados**:

> **Problema → Dados → Informação → Análise → Decisão → Benefício**

# 13. Os 5 Vs do Big Data

Analise o problema escolhido pela equipe.

| V              | Pergunta                                                   | Resposta da equipe |
| -------------- | ---------------------------------------------------------- | ------------------ |
| **Volume**     | Existe uma grande quantidade de dados?                     | Moderado: cresce a cada semestre, com dados de todas as turmas e anos anteriores. |
| **Velocidade** | Os dados são gerados ou processados rapidamente?           | Baixa/média: notas e frequência são atualizadas periodicamente, não em tempo real. |
| **Variedade**  | Existem diferentes tipos ou formatos de dados?             | Sim: notas (números), frequência (registros), dados socioeconômicos (texto/categorias). |
| **Veracidade** | Os dados podem apresentar erros ou problemas de qualidade? | Sim: faltas podem não ser lançadas corretamente e informações socioeconômicas podem estar desatualizadas. |
| **Valor**      | Os dados podem gerar algum benefício ou apoiar decisões?   | Sim: podem apoiar diretamente ações de retenção de alunos. |

### Qual dos 5 Vs é mais relevante para o problema?

> Veracidade

### Justifique

> Se os dados de frequência ou notas estiverem incorretos ou incompletos, qualquer análise ou alerta gerado a partir deles pode levar a decisões erradas, prejudicando a credibilidade do sistema.

# 14. Mapa do Problema de Ciência de Dados

Complete o fluxo abaixo:

```text
┌─────────────────────┐
│       PROBLEMA      │
│   Evasão escolar    │
│   no ensino médio   │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│        DADOS        │
│ Notas, frequência,   │
│ dados socioeconômicos│
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│     INFORMAÇÕES     │
│ Perfil dos alunos    │
│ em risco de evasão   │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│       ANÁLISE       │
│ Comparação de grupos │
│ e evolução no tempo  │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│       DECISÃO       │
│ Criar sistema de     │
│ alerta de risco      │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│      BENEFÍCIO      │
│ Redução da evasão    │
│ escolar              │
└─────────────────────┘
```

### Resuma cada etapa

**Problema:**

> Alta evasão escolar no ensino médio.

**Dados:**

> Notas, frequência, situação socioeconômica, idade/turno e histórico de reprovações.

**Informação:**

> Perfil e características comuns entre os alunos que evadem.

**Análise:**

> Comparação entre grupos de alunos evadidos e não evadidos, com acompanhamento ao longo do tempo.

**Decisão:**

> Implementar um sistema de alerta para identificar alunos em risco.

**Benefício:**

> Menos alunos evadindo e mais alunos concluindo os estudos.

# 17. Reflexão final

Responda individualmente ou em equipe:

> **Ter muitos dados significa necessariamente tomar boas decisões? Por quê?**

**Resposta:**

> Não. Ter muitos dados não garante boas decisões se esses dados forem de baixa qualidade, mal interpretados ou analisados sem um objetivo claro. É preciso que os dados sejam confiáveis (veracidade) e que a equipe saiba transformá-los em informação útil.
>
> Quantidade sem qualidade e sem análise adequada pode até atrapalhar, gerando conclusões erradas ou decisões baseadas em ruído em vez de padrões reais.
